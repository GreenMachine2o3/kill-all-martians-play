# Kill All Martians - play in your browser / on your phone

Play: https://greenmachine2o3.github.io/kill-all-martians-play/

On iPhone: open the link in Safari, tap Share > Add to Home Screen, and launch it from the icon (full screen).
The first launch downloads about 280 MB of game data (use Wi-Fi); after that it's cached.

This repo only holds the built game, generated by `tools/build_web.py --publish` in the source repo. Don't edit it by hand.
